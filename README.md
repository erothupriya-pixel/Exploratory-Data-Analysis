# Exploratory Data Analysis Project

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) using Python libraries such as Pandas, Matplotlib and Seaborn.

## 📂 Dataset
Iris Dataset

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Analysis Performed
- Data Cleaning
- Statistical Summary
- Missing Value Analysis
- Data Visualization
- Correlation Heatmap

## 📈 Visualizations
- Species Count Plot
- Pairplot
- Heatmap

## 🔍 Insights
- Iris-setosa is easily distinguishable.
- Petal features are highly correlated.
- Dataset contains no missing values.
